# B2B PROJECT NOTES — JOCK-B2B

> **ВАЖНО:** Это отдельный проект, не связанный с интернет-магазином JOCK NUTRITION. Не трогать файлы магазина. Отдельный репозиторий, отдельная БД.

---

## Контекст

- Небольшая команда: 5-6 человек, пара на складе, остальные — торговые представители (ТП)
- Нет директоров, супервайзеров, сложной иерархии
- ТП развозят сыр и несколько позиций, подключают новые магазины
- Нужно простое, удобное мобильное приложение для работы ТП

---

## Роли

- `manager` — админ, заводит товары, цены, скидки, акции, клиенты (магазины), маршруты, видит всё
- `agent` — ТП, видит только свои точки и заказы, оформляет заказы
- `warehouse` — склад, видит заказы, остатки, отгрузки, финансы, статусы

---

## Основные экраны

1. **Расписание** — по дням недели (ПН, ВТ, СР, ЧТ, ПТ, СБ, ВС), список точек на день
2. **Карточка точки** — название, адрес, контакты, история заказов, долги/остатки
3. **Каталог** — адаптированный под B2B, скидки/акции прямо на карточках
4. **Карточка товара** — цена, остаток на складе, акции/скидки, состав/описание
5. **Корзина → Накладная** — список, количество, итог, PDF/картинка → системный шаринг
6. **История заказов** — по точкам, по датам
7. **Избранное** — у ТП, для быстрого доступа к частым позициям

---

## Каталог товаров

- Один каталог для всех точек
- На карточке товара сразу видно:
  - название
  - цена за единицу
  - остаток на складе
  - скидки/акции (бейджи)
  - единица измерения (шт, кг, упаковка, ящик)
- Категоризация: есть (сыры, молочка, напитки и т.д.)
- Дополнительная информация при открытии карточки: состав, описание, условия хранения
- Цена на карточке одна, но ТП при оформлении заказа может её изменить вручную
- На карточке/в заказе показывать: старая цена, новая цена, акции

---

## Скидки и акции

Типы:
- Старая цена / новая цена
- «1 берёшь — 1 в подарок» / «10 берёшь — 11 в подарок» (числа настраиваемые)
- Срок действия: до какого-то числа
- Повод: месяц, мероприятие, праздник
- Персональные акции для конкретного магазина (по выбору админа/главного)
- Общие акции для всех

Хранение в БД: таблица `promotions`
- тип (percent / bundle / gift / old_new)
- значение (процент или количества)
- дата начала / окончания
- привязка к товару или категории
- target_client_id (nullable) — персональная для клиента
- заголовок и описание акции
- active

## Заказы и накладная

- ТП оформляет заказ для магазина
- ТП видит только свои заказы; manager и warehouse видят все заказы
- Редактирование заказа: разрешено после отправки, пока статус не `shipped` или `cancelled`
- История заказов по клиенту с фильтром по дате — есть
- После оформления — генерация накладной (PDF + PNG)
- **Многостраничная**: если много позиций — автоматический перенос на следующие листы
- **Повторная печать**: если накладная потеряна/повреждена — можно перепечатать
- Отправка: системное меню «Поделиться» (Web Share API) → WhatsApp/Telegram/email/Bluetooth
- Если Web Share API не supported → кнопки «Скачать PDF», «Копировать текст», «WhatsApp»
- **Возвраты**: отдельный раздел, отдельная накладная на возврат, списание с ТП
- Статусы заказа:
  - `draft` — черновик
  - `pending` — отправлен ТП, ожидает сборки на складе
  - `picked` — собран на складе
  - `shipped` — отгружен, передан ТП
  - `cancelled` — отменён
- Каждое изменение статуса фиксируется: кто, когда, комментарий

## Маршруты и расписание

- ТП заходит → видит текущий день недели → список точек на день

## Работа склада и отгрузка

- ТП собирает заказы за день
- На следующий день на складе открывается раздел «Заказы»
- Визуально: блоки по магазинам — название магазина, количество наименований, какой ТП собрал
- Работа по реализациям/долгам: товар под реализацию в долг или через накладную
- Накладная печатается на складе и отдаётся с заказом ТП
- Статусы заказа на складе:
  - `pending` — новый заказ, ожидает сборки
  - `picked` — товар собран, ждёт отгрузки
  - `shipped` — товар отгружен, передан ТП
  - `cancelled` — отменён
- Каждое изменение статуса фиксируется по времени (кто, когда поменял)
- В блоке заказа полностью виден заказ: список товаров, количество, цены, итог
- PDF-накладная доступна сразу в блоке заказа на складе

## Админка / Склад: разделы

### 1. Заказы
- Список заказов по датам, по ТП, по магазинам
- Фильтры: дата, ТП, статус, магазин
- Блок по магазинам: название, количество наименований, ТП, статус отгрузки
- Детализация заказа: товары, количество, цены, итог
- PDF-накладная для печати
- Смена статусов: собран → отгружен (с фиксацией времени и ответственного)

### 2. Финансы
- Добавление каждого сотрудника (ТП, складские)
- Анализ по сотрудникам:
  - сколько денег принёс (оборот по заказам)
  - сколько должен (долги по клиентам/реализациям)
  - эффективность за период
- Возможность видеть историю по каждому сотруднику

### 3. Товары и остатки
- Управление каталогом: добавление, редактирование, удаление товаров
- Изменение остатков: новый завоз, брак, просрочка
- История движения товаров: приход, расход, списание
- Учёт продаж: что продано, сколько осталось

### 4. Клиенты (магазины)
- Добавление, редактирование, удаление клиентов
- Карточка клиента:
  - название магазина
  - адрес
  - телефон
  - контактное лицо
  - примечания
  - назначенный ТП
  - дни посещения (из маршрута)
  - история заказов
  - долги/реализации
- Поиск и фильтры по названию, ТП, статусу
- Возможность массового назначения ТП

### 5. Маршруты
- Назначение клиентов ТП по дням недели
- Визуальный планировщик: ПН/ВТ/СР/ЧТ/ПТ/СБ/ВС
- Drag-and-drop или выбор из списка
- Порядок визитов в течение дня
- Повторяющиеся графики

### 5. Отчёты
- Отчёт по заказам за период
- Отчёт по остаткам
- Отчёт по сотрудникам
- Экспорт в текст/WhatsApp (Excel/PDF позже)

### 6. Возвраты
- Список возвратов по ТП, по магазинам, по датам
- Детализация возврата: товары, количество, причина, сумма
- Статусы: `pending` (ожидает обработки), `processed` (обработан), `cancelled` (отменён)
- Списание с ТП
- PDF-документ возврата

### 7. Финансы
- Добавление каждого сотрудника (ТП, складские)
- Зарплата: варианты расчета — оклад, % + оклад, % от продажи, % от прибыли
- Анализ по сотрудникам:
  - сколько денег принёс (оборот по заказам)
  - сколько должен (долги по клиентам/реализациям)
  - возвраты
  - эффективность за период
- История выплат/авансов
- Возможность видеть историю по каждому сотруднику
